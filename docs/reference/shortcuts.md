# Keyboard shortcuts

Most actions are on the menus and toolbars; these are the keyboard shortcuts.

| Shortcut | Where | Action |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | SCADAScop | Start all channels |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | SCADAScop | Stop all channels |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Point / monitor tables | Select all rows |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Point / monitor tables | Copy the selected rows as text |
| <kbd>Esc</kbd> | Tables | Clear the selection |
| Click / <kbd>Ctrl</kbd>+click / <kbd>Shift</kbd>+click / drag | Tables | Extend or box-select rows |
| <kbd>Ctrl</kbd>+click / drag on empty canvas | Display editor | Add to / rubber-band the selection |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Display editor | Select every object |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Display editor | Undo / Redo |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Display editor | Duplicate the selection |
| <kbd>Del</kbd> | Display editor | Delete the selection |
| Arrows / <kbd>Shift</kbd>+arrows | Display editor | Move the selection by 1 px / one grid step |
| <kbd>Esc</kbd> | Display editor | Clear the selection, cancel placing an object |

!!! note "Draft"
    This list will grow as shortcuts are confirmed across the tools. If a
    shortcut you use is missing, it probably has a menu or toolbar equivalent.
