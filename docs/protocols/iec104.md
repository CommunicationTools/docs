IEC104Scop is the IEC 60870-5-104 pair (TCP): **IEC104Scop Master** and
**IEC104Scop Slave**. It shares the station/ASDU model and point detail with the
IEC 101 tools.

## Addressing

A connection carries one or more **stations**, each with a **common (ASDU)
address**. APCI parameters (k, w, t1, t2, t3) are per channel.

## Points

Points share one IOA space across kinds: single/double points, measured values
(normalized / scaled / float), step position, bitstrings, integrated totals, and
commands (single / double / regulating / setpoint). Each has a cause/class and a
time-tag mode.

## Master

- STARTDT / STOPDT, general and counter interrogation, clock sync, commands with
  select/execute, and reading the event buffers.
- Point Detail shows a point's full decoded state.

## Slave

- Simulate a station: serve the image, emit spontaneous events (optionally
  double-transmitted), answer interrogations and commands.
- **Send End of Initialization** from the RTU context menu (M_EI_NA_1), which a
  master answers with an interrogation.
- **Communication Tests…** — APCI and application-layer fault injection
  (see [Simulate faults](../how-to/simulate-faults.md)).
