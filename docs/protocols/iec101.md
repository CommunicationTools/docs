IEC101Scop is the IEC 60870-5-101 pair (serial, FT1.2): **IEC101Scop Master** and
**IEC101Scop Slave**. It shares the ASDU/point model with IEC 104.

## Addressing

Each station has a **link address** (FT1.2) and a **common (ASDU) address**. A
channel can be **unbalanced** (the master polls; events wait in class 1/2
buffers) or **balanced** (point-to-point). One line can carry several link
addresses (multi-drop).

## Master

- Link reset and start-up, class 1 / class 2 polling, interrogation, clock sync
  and commands.
- Per-station "Own link address", online state and start-up interrogation.

## Slave

- Simulate one or more secondaries on a line, with class 1 / class 2 buffers,
  FCB handling and DFC flow control.
- **Send End of Initialization** from the RTU context menu (class 1 data).
- **Communication Tests…** — FT1.2 link and application-layer fault injection:
  deny class 2, NACK, link-not-functioning, DFC busy, silent, bad checksum,
  ignore FCB, FCB filter, and the shared application faults
  (see [Simulate faults](../how-to/simulate-faults.md)).
